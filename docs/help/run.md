# 运行

运行页用来启动一轮、观察它走到哪一步，并处理需要人决定的事项。左栏“运行”下是“新建 Run”和 Run 列表；中栏是本轮的泳道；右栏上方查看所选的一步，下方是交付目标或人工待办。

## 启动一轮 {#start}

1. 在左栏选“运行”→“新建 Run”。
2. 在“项目”里选定项目。中栏随即列出这一轮会走到的节点。
3. “Run 命名”默认是项目标识加递增序号，启动前可以修改。
4. 在右栏下方“描述本轮交付目标”里写清要求。需要时按“上传附件”附上文件。
5. 需要时点中栏的活动格子，在右栏为这一步选择模型、推理强度、Fast、上下文长度和 Skill。
6. 按“启动”。

> [!NOTE]
> 附件放进本轮目录，之后的活动都可以直接读取。

## 草稿与复制 {#draft}

- 尚未启动的 Run 会自动保存为草稿：交付目标、附件、各节点的 Skill 与各角色的模型设置，停止输入约一秒后保存到服务端。切换 Run、新建或关闭页面前也会先保存。
- “保存 Run 配置”立即保存一次。草稿出现在 Run 列表里，打开后可以继续修改再启动。
- Run 列表每一行右侧有“复制”，把那一轮的配置复制到新建表单，确认后启动。
- 删除按钮会先确认。删除后这一轮的记录不能恢复，待开发项目仓库里的文件保留。

## 读懂泳道 {#rail}

中栏按角色分行，只列出这一轮会走到的节点。格子上的标记表示状态：

| 标记 | 含义 |
|------|------|
| ✓ | 已完成 |
| ● | 进行中 |
| ! | 等待人工或中断 |
| ‖ | 已暂停 |
| ■ | 已停止 |
| 琥珀色底 | 决策点在等你批复 |

- 决策点格子前是方框图标，批复后框内打勾。
- 当前步骤与“右栏正在查看”的格子用不同的底色区分，图例在泳道下方。
- 右栏顶部的阶段标记表示整轮的阶段，例如“本轮运行中”“本轮等待人工”，不是所选那一步的状态。

## 处理人工待办 {#todo}

一轮停下来等人时，中栏上方出现提示和“去处理”，右栏下方显示“人工待办”。人工待办有三种：

- **决策点**：阅读“待审阅”列出的产物，选择决定后提交。点产物名可以在右栏阅读全文。
- **需求澄清**：角色对交付目标有疑问。在“澄清答复”里逐条回答，这一项必填。
- **回退升级**：某个活动回退次数用尽。在“升级决策”里选择“继续——再跑开发”“暂停——保留现场”或“终止——结束本轮”。

处理时可以在附言里补充说明，也可以上传附件，随批复一起提交。按“提交并续跑”后，这一轮从停下的地方继续。

## 批复决策点 {#gate}

- “决定”里有“批准——继续流程”和一个不通过选项。流程为这个决策点设了“不通过时”的去向时，不通过选项写作“不通过——退回‘节点名’”，附言会作为需要修复的问题交给那个活动；没有设去向时写作“驳回——结束本轮”。
- 择一决策点跟在“对照择一”的并行之后。阅读区第一节是两路对照，在“采用哪一路”里选定一路；未采用的各路改动保存为本轮目录下的补丁文件。

## 逐项审批 {#gate-items}

决策点列出了决策项时，“待审阅”下方是逐项卡片：

1. 每张卡片给“通过”或“不通过”，再点一次取消。标为“可选”的条目可以不答。
2. 选“不通过”时，填写“不通过的原因”。原因原样交给退回的活动。
3. 卡片顶部显示已决数量和不通过数量。“其余全部通过”一次标记剩下的条目。
4. 按提交按钮。

汇总规则在流程里设定：

- **全部通过才放行**：不显示“决定”，提交按钮按逐项结论自动改写。必答项未答完时写“还差 N 个必答项”且不能点；有不通过时写“不通过——退回‘节点名’”或“不通过——结束本轮”；否则写“全部通过——继续”。
- **只作核对清单**：逐项结论只作记录，最后仍由人在“决定”里选择。

## 暂停、停止与续跑 {#control}

- **暂停**：当前节点做完后停住，已完成的节点不会重做。之后可以继续。
- **停止**：结束本轮，确认后不能再从当前节点接着跑。
- **续跑**：一轮因服务中断或节点失败而停住、并非人按了“停止”时，出现“续跑”，从中断的节点接着做。“启动”仍是新开一轮。

## 查看会话与历次决定 {#inspect}

- 点泳道里的一格，右栏上方显示这一步的模型与 Skill，下方是会话，包括子代理的调用与结果。
- 点已经批复过的决策点，右栏列出历次决定：当时待决的内容与待审阅产物、所选决定、逐项结论与附言。
- 需求澄清与回退升级的答复，记在当时待办所在的格子上。
- MCP 是全局配置，对所有角色可见，在[配置](config.md#agent)里查看。

## Run 列表 {#list}

- 左栏 Run 列表按更新时间排列，可以按阶段筛选：运行中、已暂停、中断、等待人工、已完成、已驳回、已停止。
- 点一行打开那一轮。地址栏带有这一轮的标识，可以复制给同事直接打开。
