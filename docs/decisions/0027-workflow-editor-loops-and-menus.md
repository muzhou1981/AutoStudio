# 0027 · 流程编辑：回退与不通过画成虚线、级联菜单、撤下原文 YAML

- 状态：已实现
- 日期：2026-11-12
- 关联：[0025](0025-role-model-params-and-menu.md)（运行页角色模型的级联菜单）。

## 背景

流程编辑页审视后发现：

1. 回退（`returns_to`）画成从节点下边接入的虚线，与第 8 节「从右侧绕回左侧」不符；决策点的不通过去向（`reject_to`）完全不画，内置「NPU 算子开发」的分支在图上看不出来。
2. 连线不能选中、不能改、不能删；新节点只能插在「结束」之前，再逐格上移。
3. 节点设置与添加栏都是平铺表单：右栏一列下拉框，底部一行「输入框 + 按钮」三组；删除流程紧挨保存，「复制」出现两次。
4. 原文 `workflow.yaml` 可以整份覆盖，是绕过表单校验的后门。同时，表单保存只带回编辑器认识的字段，复制内置流程后用表单保存，会丢掉 `profile`、`workspace` 与节点的 `handler`、`routes`、`when`、`instruction`、`effect`、`primary_output` 等；原文覆盖是唯一能保住它们的途径。

## 决定

1. **主路径保持线性。** 流程仍是节点的有序排列，加回退与不通过两类跳转；不改成任意有向图，后端模型、校验与运行时不变。
2. **两类跳转都画成虚线。** 从起点节点右侧流出，沿泳道下方各自的一条通道绕行，从目标节点左侧流入。回退为琥珀色并标注最多轮数，不通过为红色。连线与标签可点选；选中后可经菜单改目标、改轮数、删除，也可拖动箭头端圆点改去向，不合规则的目标在拖动时标红。
3. **就地插入。** 相邻节点之间的连线中点有「+」，画布上方有「添加节点」（插在选中节点之后）。二者打开同一个级联菜单：活动（下级为角色）、决策点、并行、子图（下级为子图列表）。
4. **节点设置用级联菜单。** 与运行页模型菜单同一套样式与键盘操作：摘要芯片，一级行写当前值，悬停或聚焦弹出下级，右方向键进入、左方向键或 Esc 返回。输入、输出仍是列表编辑，改为可折叠分组，摘要写项数与待补项数。设定回退时默认最多 3 轮。
5. **撤下原文 YAML。** 删除编辑区的原文面板与 `PUT /api/workflows/{id}/raw`。「更多」里提供「导出 YAML」（上次保存的版本），导入仍走左栏「导入」。
6. **复制不调用模型。** 复制流程的标识由原标识加 `-copy` 派生，不再把「副本 · 原标题」交给模型翻译；翻译要等一次完整的模型调用，复制因此要等很久才进入新流程。
7. **连线分道。** 列间空隙加宽到 56px，分出流出虚线、顺序拐弯、流入虚线三道；虚线在节点中线下方 11px 进出，箭头前留直线，箭头用固定尺寸。
8. **泳道图适应中栏宽度。** 监听画布容器宽度，富余时加大节点间距；放不下时不缩放画布（缩小后节点文字难以辨认），保持原尺寸并横向滚动。
9. **保存带回未管理字段。** 前端载入节点时保留编辑器没有控件的字段，保存时原样提交；`SaveWorkflowBody` 增加 `profile`、`workspace`、`rail`，交给既有校验。

## 后果

- 内置流程的不通过分支在编辑页可见；复制后的内置流程可以直接用表单保存，不再丢失系统节点与运行档案。
- 系统节点的 `routes`、`next` 仍不画在图上，也没有控件；需要改它们时，导出 YAML、修改后从「导入」另建一份。
- 决策点的 `returns_to` 在运行时不生效，菜单不再为决策点提供回退，已有的仍可清除。
- 撤销与重做仍未提供。
