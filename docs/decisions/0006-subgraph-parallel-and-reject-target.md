# 0006 · 子图、并行与驳回去向

- 状态：已接受
- 日期：2026-11-09

## 背景

[ADR 0005](0005-selected-workflow-compiles-run-graph.md) 把一份线性的流程编译成当轮的图。§1.1 还要求子图复用、支路同时进行，以及决策点驳回后前往已有节点。

## 决策

1. 子图仍是一份 `workflows/<id>/workflow.yaml`，用 `subgraph: true` 标出。它可以出现在插入列表里，也可以被项目选为当轮流程。
2. 插入只在父流程里占一格。编译时展开内部活动和决策点，标识加上父节点前缀。子图不能引用自身，形成环时拒绝保存。默认流程（`engine: default`）不能当作子图插入。
3. 页面上，正在编辑的子图不能再插入另一份子图。内置的整网适配流程在文件里已经包含算子子图，不靠页面再套一层。
4. 并行节点至少两条支路。编译成一个分叉和汇合：各支路同时进入，全部结束后才到下一格。支路里的同名产物在汇合时合成一份；多路都写了同一产物时，按支路名分节。
5. 决策点可以声明「不通过时前往」。未声明时，驳回仍结束本轮。通过仍进入下一格。第一版不另写条件表达式。

## 后果

- 运行泳道展示展开后的活动和决策点，编辑区仍把子图和并行各显示成一格。
- 并行中的决策点仍会停下等人。两条支路同时走到决策点时，这一轮在这些决策点上等待。
