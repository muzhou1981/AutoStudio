# 0038 · 隐藏内置的通用软件开发流程

- 状态：已采纳
- 日期：2026-11-13

## 背景

人要求去掉内置的“通用软件开发”（`factory_default`），认为它是早期的测试数据。该流程实际是引擎的默认流程：`workflows/default.py` 从它读取节点与路由，`general_software`、`web_app`、`middleware` 三个场景与示例项目选用它，新建项目时后端也把它写作占位流程。直接删除会使默认图与已有项目无法运行，而 `default.py` 由人工编写，不在本次改动范围内。

## 决定

1. 流程文件支持顶层字段 `hidden: true`。`list_workflows` 返回 `hidden`，接口保持完整列表，标识查重等后端用途不受影响。
2. `factory_default` 标记为隐藏。流程编辑页与项目页的“选择流程”不列出隐藏流程；当前已打开或项目已选用的隐藏流程仍然列出，保证显示正确。
3. 项目表单保存时，若选择了与原值不同的隐藏流程，返回“这个流程已停止选用，请选择其他流程。”已选用它的项目保存不受影响。
4. 新建项目时不再写入 `profile_id: factory_default` 占位，由表单保存时写入人选择的流程。
5. 复制隐藏流程得到的副本不带 `hidden`，可以正常选用。

## 取舍

- 没有删除文件或改写 `default.py`：保留引擎默认图与已有运行记录的可追溯性；以后若决定彻底移除，需要另行修改 `default.py`、场景与示例项目。
