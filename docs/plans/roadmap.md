## 当前开发计划

除 M9 外，M0 至 M10 均已完成。M9 继续暂停。M10 已用 Stub 跑通活动、决策点和回退。

M11 至 M20 已完成，M9 除外。§1.1 里写明的流程机制都已落地。

仍留着、且不在这一批里的事项：场景级 MCP 与 Skill 开关、OpenAI 后端、M9 递归改进。所选流程尚未用 Cursor 后端整图跑过。界面改法见 [ui-ux.md 第 13 节](../design/ui-ux.md)。
