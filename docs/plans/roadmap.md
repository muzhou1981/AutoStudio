## 当前开发计划

除 M9 外，上表里程碑均已完成。M9 继续暂停。M10 已用 Stub 跑通活动、决策点和回退。

仍留着的事项：场景级 MCP 与 Skill 开关、OpenAI 后端、M9 递归改进。所选流程尚未用 Cursor 后端整图跑过。
