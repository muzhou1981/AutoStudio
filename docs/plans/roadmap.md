## 未完成项优先级

排序依据：先让一轮运行的代码和文档留在目标项目里并能复查。需求 7 要求接着使用 SDK 默认模型或模型路由，并复用该后端已有的 MCP、规则与 Skill，验证闭环才能在工作树里写代码并跑测试。成本账本给后续复盘提供证据。CLI 与后端可选配置补入口，不挡住交付。进化与递归放在已有真实运行数据之后。

| 顺序 | 里程碑 | 原因 |
|------|--------|------|
| P0 | M3 | 已禁止 `git push`，同一目标同时只允许一个写入者。产物落盘时对照模板标题写出 `template_gaps.md` |
| P1 | M5 | 已默认 Auto（`default`），并在目标工作树加载 Cursor 规则。场景里按配置启用或停用 MCP/Skill 仍在需求 10、11 |
| P2 | M4 | 工作树测试命令的输出已作为验收证据，能把整图送到最终交付关卡。影响架构的变更会回到架构关卡 |
| P3 | M6 | 项目 YAML 可按角色指定 `backend` 与 `model`。整图 Stub 跑完后 `cost_ledger` 含调用记录。Cursor 用量和 OpenAI 仍要等桥接 |
| P4 | M8 | CLI 可启动、查看关卡与成本，并用 `--reply` 提交项目经理澄清。API key 与后端配置可写入 `.env` |
| P5 | M7 | 改进前后跑分已有。提案须先 `proposal approve` 写入 `evolution/ledger.md`，才能 `apply` 改角色文件 |
| P6 | M9 | 暂停：不再循环重试。代理对 `api5.cursor.sh` 的 CONNECT 仍为 HTTP 500。需要时再手动运行 `python scripts/self_improve.py` |
